내 Notion 토큰과 DB ID를 입력하면 이 기기의 할일이 내 Notion DB와 양방향 동기화됩니다.

📖 처음이세요? 설정 가이드 보기
  1. ① 할일 템플릿을 열어 내 Notion에 Duplicate(복제)한 뒤 사용
  2. ② my-integrations에서 New integration 생성 후 Internal Integration Token 복사
  3. ③ 복제한 DB 페이지 → 우측 상단 ⋯ → Connections → 방금 만든 integration 연결
  4. ④ DB 페이지 URL 중 notion.so/…/여기32자리?v=… 부분이 Database ID

🔒 토큰은 이 브라우저에만 저장되며 서버에 보관되지 않습니다.
